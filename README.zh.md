# Arrosam’s Productive Choice

[English](<README.md>)

## 概述

由 Arrosam 挑选的 [DeepSeek Harness（DSH）](<https://github.com/deepseek-ai/deepseek-harness>) 插件目录，面向日常高效工作。每条收录记录插件解决的问题、Arrosam 的选择理由，以及使用前需要了解的事项。

本仓库是精选目录，不是可安装的插件组合，也不代表 DSH 官方推荐。目前尚未收录插件。

## 目录

- [推荐插件](#推荐插件)
- [使用与限制](#使用与限制)

## 推荐插件

通过 [Issue](<https://github.com/Arrosam/arrosams-productive-choice/issues>) 或 Pull Request 提供插件的上游链接、使用场景，以及已知的前提条件或风险。条目所需信息见[收录规范](<CONTRIBUTING.zh.md>)。最终由 Arrosam 决定是否收录。

## 使用与限制

安装与配置请遵循各插件的上游文档。条目必须区分插件、配置组合（profile bundle）与库；本目录不提供统一安装命令。

收录不等于安全审计，也不保证兼容所有 DSH 版本。使用前请查看条目的验证记录、上游许可证、权限、凭据要求及潜在费用。上游项目保留各自的许可证。
