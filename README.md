## Summary

A personal selection of [DeepSeek Harness (DSH)](<https://github.com/deepseek-ai/deepseek-harness>) plugins, curated by Arrosam for productive work. Each entry records what the plugin helps with, why Arrosam chooses it, and what users need to know before using it.

This repository is a curated directory, not an installable plugin bundle or an official DSH recommendation. No plugins are listed yet.

## Suggest a plugin

Open an [issue](<https://github.com/Arrosam/arrosams-productive-choice/issues>) or a pull request with the plugin’s upstream link, intended use case, and any known prerequisites or risks. See the [collection guidelines](<CONTRIBUTING.md>) for the information required for an entry. Arrosam makes the final selection.

## Usage and limitations

Follow each plugin’s upstream documentation for installation and configuration. An entry must distinguish a plugin from a profile bundle or a library; this directory does not provide a universal installation command.

A selection is not a security audit or a guarantee of compatibility with every DSH version. Check the entry’s verification details, upstream license, permissions, credential requirements, and possible costs before use. Upstream projects retain their own licenses.
